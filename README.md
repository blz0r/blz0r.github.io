# Shamsul Khan — QA portfolio

Live site: https://blz0r.github.io/

QA automation and software development portfolio with saved Allure reports, cross-language code examples, an Android failure investigation, and a downloadable generic QA starter.

## QA starter

Download: https://blz0r.github.io/assets/qa-template.zip

The ZIP contains 61 clean source and guide files covering TypeScript/JavaScript, Java, Python, CI configuration, and optional cloud/mobile examples. It uses synthetic application data and invented credentials. Employer originals and installed dependencies are excluded. BrowserStack is configured but unrun. See the included validation record and usage guide for scope and setup.

## Website

GitHub Pages serves the main branch root. Keep all report folders and .nojekyll intact. The generated report viewers require HTTP; for local review, double-click Start Portfolio.cmd on Windows with Python 3 installed, or run python preview.py.

The original QA repository and CI links remain private and are labelled as requiring authorized access. Public saved reports show 3 browser scenarios, 10 Java tests, 14 Python tests and 2 Android scenarios. The separate JavaScript API suite has 7 passing checks recorded in the original JUnit evidence. Language versions overlap; these counts are not distinct requirements or production coverage.
