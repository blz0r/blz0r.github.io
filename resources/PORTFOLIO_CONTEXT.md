# Portfolio context

## Suggested project description

I built this reusable QA starter to show how I structure browser and API testing across TypeScript/JavaScript, Java and Python. The versions share a synthetic application and core requirements, making the design and language differences easy to compare.

The project covers readable scenarios, reusable page objects, data-driven API checks, runner configuration, failure screenshots, Allure reporting, CI definitions and documentation. Cloud and mobile examples are opt-in extensions with their verification status stated separately.
